# AI Portfolio Assistant

Embeddable AI chatbot that allows recruiters to interact with a developer's portfolio in a conversational way.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- OpenAI API

## Goal

Provide a professional, structured, and interactive way to explore a developer profile.

## Features (MVP)

- Chat-based interaction
- Structured profile data
- Recruiter-oriented responses
- Embeddable widget

## Status

MVP in development
